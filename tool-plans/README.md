# Tool plans

Plans for tools that are not built yet, or only in part. One folder per plan.

| Plan | What it is | Where it stands |
| --- | --- | --- |
| [Agent-assisted hotfixes](agent-hotfix/) | Agents find google/fonts issues that a script can fix (no design work), prepare the fix with fontspector and diffenator reports, and wait for a person's approval before any PR. | Phase 0 (triage and feasibility) runs in the [GF Issue Dashboard](https://emmamarichal.github.io/gf-issues-dashboard/). |
| [Proofing tools for `gftools qa`](gftools-proofing/) | Two proofs in diffenator3 / gftools: every glyph across the masters, and a comparison with reference families of the same script. | Browser prototype: [Reference proofs](https://emmamarichal.github.io/gf-issues-dashboard/reference-proofs/). |
