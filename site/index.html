Font bugs, most to least feasible

The fontspector column summarises the googlefonts profile report on the family's current binaries (fontbakery 1.1 run offline, network checks excluded): No FAIL or Scriptable FAILs only = a hotfix can pass; Glyph fixes needed or Glyphset coverage incomplete = the family no longer meets current specs, so a hotfix alone will likely fail CI. Maybe fixed? shows Likely when the font has been updated since the issue was opened.

Issues that could be closed

Likely: the font the issue is about has been updated since the issue was opened, or the evidence is direct (font added, family removed, a commit that closes the issue, submission not meeting requirements). An update does not prove the problem is fixed, so check before closing. To verify: inactive for over 3 years with little interest, or a commit mentions the issue. Nothing is closed automatically.
