Font Social Post Generator

Google Fonts · draft a social post + gather images from a font's repo

Settings (API key, model, GitHub token)

Kept only in this browser (localStorage) and sent straight from your browser to api.anthropic.com — it never passes through any server of ours. Don't use this on a shared computer.

Only needed if you hit GitHub's rate limit from generating a lot of posts in a row. A read-only "public repo" token is enough.

Font

Paste a fonts.google.com URL, the designer's own GitHub repo (e.g. github.com/maxesnee/savate), a github.com/google/fonts link, or just the family name.

Images found

Pulls METADATA.pb, the description/article, and repo images live from github.com/google/fonts and the designer's own source repository. Nothing is stored anywhere except your browser. See README.md for setup.
